# 部署与使用说明（Windows）

本文档面向想自己跑起来或自己打包的用户。

## 一、环境要求

| 项 | 要求 |
| --- | --- |
| 系统 | Windows 10 / 11（64 位） |
| Python | 3.10 或更高（开发环境为 3.13） |
| 微信 | Windows 版，需要**打开聊天窗口**并保持在屏幕上 |
| 账号 | 一个 OpenRouter API Key（[申请入口](https://openrouter.ai/keys)） |

## 二、从源码跑起来

```bat
cd jev-xianhui-windows
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python main.py
```

首次运行会加载本地 OCR 模型，慢一两秒属正常。

## 三、首次配置（三步）

程序主界面是三张状态卡，按顺序做就行：

**第一步 · 填 OpenRouter Key**
把 `sk-or-v1-…` 粘进输入框回车。密钥存在 `%APPDATA%\JevPriority\config.json`，只在判断请求里随附，不会上传到别处。

**第二步 · 打开微信聊天窗口**
打开任意一个微信聊天窗口，让它显示在屏幕上。点「重新检测」，卡片变绿说明已找到。
> 悬浮窗置顶会浮在微信上方，但不影响截图 —— 我们只截微信自己的窗口。

**第三步 · 开启自动判断**
勾上「自动判断新消息」。三张卡都绿了，顶部会显示"全部就绪"。

然后点 **「开始监听」**，悬浮窗出现，开始工作。

## 四、悬浮窗怎么用

| 操作 | 效果 |
| --- | --- |
| 按住顶部横条拖动 | 移动，**松手自动吸附到最近的屏幕边缘** |
| 点「—」 | 收起成小横条 / 展开 |
| 点某条消息 | 从列表移除（回复请回微信里发） |
| 点「×」 | 关闭悬浮窗 |

颜色含义：

| 颜色 | 含义 |
| --- | --- |
| 🔴 红 | 马上回 |
| 🟡 黄 | 尽快 |
| ⚪ 灰 | 可以晚点 |
| 🔵 蓝 | 正在判断 |

## 五、打安装包

需要 [Inno Setup 6](https://jrsoftware.org/isdl.php)（免费）。

```bat
packaging\build_installer.bat
```

脚本会依次：装 PyInstaller → 用 `jev.spec` 打包 → 用 Inno Setup 生成安装程序。

产物：

```
dist\XianHui\               ← 免安装的完整程序目录（可直接压缩分发）
packaging\output\XianHui-Setup.exe   ← 带安装向导的安装包
```

没装 Inno Setup 也能跑：脚本会停在打包步骤，`dist\XianHui\XianHui.exe` 直接双击就能用。

## 六、常见问题

**Q：点「重新检测」一直找不到微信？**
A：确认微信窗口是**可见**的（没最小化），且标题里含"微信"或"WeChat"。如果你改过窗口标题，可在 `%APPDATA%\JevPriority\config.json` 的 `watch_titles` 里加上关键字。

**Q：判断一直失败？**
A：点「测试连接」。若报 401，是 Key 不对；若超时，检查网络能否访问 `openrouter.ai`。

**Q：读到的消息文字有错？**
A：OCR 对清晰的正文字体识别率很高，小字号或浅色文字可能出错。把微信窗口调大一点会明显改善。

**Q：会读到我的聊天记录并存下来吗？**
A：不会。截图只在内存里用完即弃，消息文字只在判断那一刻发给模型接口，不留历史、不写日志。重启程序列表清空。

**Q：会不会被微信检测到？**
A：本程序只做两件事：读取窗口画面（系统公开能力），不注入、不 hook、不修改微信任何数据、不自动发送。对微信而言它只是一个"看着你的窗口"的普通程序。

**Q：微信更新后失灵了？**
A：消息解析依赖左右气泡的相对位置。大改版后需要重新校准 `capture/parser.py` 里的比例阈值。

## 七、卸载

- 用安装包装的：设置 → 应用 → 找到 先回 → 卸载。
- 免安装的：直接删掉 `dist\XianHui` 目录。
- 想连配置一起清掉：删掉 `%APPDATA%\JevPriority` 目录。
